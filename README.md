# SimplePhysicalEngine

**SimplePhysicalEngine** — это образовательный проект, цель которого — создание наглядных физических визуализаций с помощью C++ и Raylib. Проект задуман как песочница для изучения и демонстрации основ физики: движения материальных точек, сил, импульсов и столкновений.

##  Возможности

*   **Симуляция материальных точек**: каждая точка обладает массой, радиусом, положением и вектором скорости.
*   **Применение сил**: поддержка постоянных и переменных сил (например, гравитации), действующих на точки.
*   **Упругие столкновения**: корректная обработка столкновений между точками с сохранением импульса и кинетической энергии.
*   **Визуализация в реальном времени**: отрисовка сцены с помощью библиотеки Raylib. Положение точек в метрах преобразуется в пиксели экрана с настраиваемым масштабом.
*   **Образовательная направленность**: код написан так, чтобы его было легко читать и модифицировать для проведения собственных экспериментов.

##  Быстрый старт

### Требования

*   **Компилятор C++**: поддерживающий стандарт C++17 (GCC, Clang, MSVC).
*   **CMake**: версия 3.14 или выше.
*   **Git**: для автоматической загрузки библиотеки Raylib.
*   **Raylib**: библиотека загружается автоматически во время сборки через `FetchContent`, поэтому отдельно устанавливать её не нужно.

### Сборка проекта

1.  **Клонируйте репозиторий**:
    ```bash
    git clone https://github.com/MrVaz21/SimplePhysicalEngine.git
    cd SimplePhysicalEngine
    ```

2.  **Создайте директорию для сборки и перейдите в неё**:
    ```bash
    mkdir build
    cd build
    ```

3.  **Сконфигурируйте проект с помощью CMake**:
    ```bash
    cmake ..
    ```
    *При первой конфигурации CMake автоматически скачает и подготовит библиотеку Raylib.*

4.  **Соберите проект**:
    ```bash
    cmake --build .
    ```

5.  **Запустите исполняемый файл**:
    *   **Windows**: `./SimplePhysicalEngine.exe` (или `.\\SimplePhysicalEngine.exe`)
    *   **Linux/macOS**: `./SimplePhysicalEngine`

### Альтернативный способ (Visual Studio Code)

Если вы используете VS Code с расширением **CMake Tools**, просто откройте папку проекта. Расширение автоматически обнаружит `CMakeLists.txt`. Вам останется выбрать компилятор (Kit) на панели CMake и нажать кнопку **Build**.

##  Как это работает

### Материальная точка (`material_point`)

Класс `material_point` представляет собой физическое тело в 2D-пространстве. Он хранит:
*   `x`, `y` — положение в метрах (система СИ).
*   `speed` — вектор скорости (`vector2`).
*   `mass` — масса тела.
*   `radius` — радиус тела (для обнаружения столкновений).
*   `forces` — список действующих на точку сил.

Ключевые методы:
*   `apply_force(...)` — добавить или обновить силу.
*   `apply_impulse(...)` — мгновенно изменить скорость, приложив импульс.
*   `get_accel()` — вычислить ускорение как сумму всех сил, делённую на массу.

### Движок (`simple_engine`)

Класс `simple_engine` управляет всеми точками и обновляет их состояние на каждом кадре. Основной метод — `update_points_states(double delta_time)`.

Он выполняет следующие шаги:
1.  **Интеграция**: для каждой точки обновляется положение и скорость на основе действующих сил. Используется метод **полу-неявного интегрирования Эйлера** (semi-implicit Euler), который устойчивее явного метода Эйлера.
2.  **Разрешение столкновений**: после обновления всех позиций происходит проверка всех пар точек на пересечение. При обнаружении столкновения:
    *   **Позиционная коррекция**: точки «выталкиваются» друг из друга, чтобы избежать взаимного проникновения.
    *   **Импульс**: вычисляются новые скорости по формулам упругого удара, основанным на законе сохранения импульса.

## Примеры для экспериментов

Попробуйте изменить начальные условия в `src/main.cpp`, чтобы увидеть разные сценарии:

*   **Упругое столкновение равных масс**: Если флаг collisions равен true - две точки с одинаковой массой летят навстречу друг другу. После удара они обменяются скоростями.
*   **«Поглощение» маленькой точки большой**: маленькая точка влетает в большую. Большая почти не изменит скорость, а маленькая отскочит назад.
*   **Гравитация**: добавьте точке постоянную силу `force_data(vector2(0, -9.81 * Масса точки), "gravity")`,
 чтобы имитировать падение под действием силы тяжести. Если флаг gravity в классе равен true - все объекты начнутпритягиваться друг к другу согласно закону всемирного тяготения.
